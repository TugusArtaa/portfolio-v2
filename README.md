# 🚀 Portfolio V2 – Next.js 15, Tailwind CSS (Monochrome Edition)

A modern, responsive, and minimalist monochrome personal portfolio website built with [Next.js 15](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/).  
Showcase your projects, skills, certificates, and more – with clean light monochrome aesthetics, smooth animations, and a delightful user experience.

> Dibuat sebagai proyek pribadi oleh Putu Agus Seniartawan.

## ✨ Features

- **Next.js 15** – App Router, SSG, fast navigation
- **Fully Static** – All content hardcoded, no database needed
- **Light Monochrome Aesthetic** – Clean, modern, high-contrast, minimalist design
- **Tailwind CSS 4** – Modern utility-first styling
- **Animated UI** – Framer Motion, Lottie, GSAP, and custom micro-interactions
- **Responsive Design** – Optimized for mobile, tablet, and desktop
- **GitHub Contribution Calendar** – Live contribution activity graph
- **Contact Form** – Send messages via Nodemailer (SMTP)
- **Downloadable CV** – Let recruiters download your resume
- **Accessible & SEO-friendly**

## 🛠️ Tech Stack

- **Frontend:** Next.js 15, React 19, Tailwind CSS, Framer Motion, Lottie, GSAP, Three.js
- **Contact:** Nodemailer (SMTP)
- **Other:** Howler, React Sounds, Zustand

## 🚦 Getting Started

1. **Clone this repo:**

   ```bash
   git clone https://github.com/TugusArtaa/portfolio-v2.git
   cd portfolio-v2
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Set up environment variables:**

   - Copy `.env.example` to `.env.local` and fill in your SMTP config.

4. **Run the development server:**

   ```bash
   npm run dev
   ```

5. **Open [http://localhost:3000](http://localhost:3000) in your browser.**

## 📦 Deployment

- **Vercel:**  
  Deploy instantly with [Vercel](https://vercel.com/new).
- **Other:**  
  Works on any Node.js hosting (no database required).
